# Antigravity Customization

## `.agents/skills/`
Active workspace skills discovered by Antigravity.

## `.agents/rules/`
Persistent constraints, activated by trigger mode.

## `.agents/agents/`
Custom agents/subagents for discovery, impact, modeling and review.

## `.agents/config/`
Project policy used by the lifecycle skills: artifact selection, classification, phase gates and document map.

## `.agents/catalog/`
Non-active external skill candidates and source notes.

## `.agents/hooks.json`
Workspace lifecycle hooks. Keep hooks deterministic and conservative.
