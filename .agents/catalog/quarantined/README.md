# Quarantined Skills

These are preserved copies of previously imported third-party skills for reference only.

They are intentionally outside `.agents/skills/`, so Antigravity will not discover them as active workspace skills.

Before moving any candidate into `.agents/skills/`:
- bundle referenced resources/templates/scripts;
- validate frontmatter;
- validate tool/agent dependencies;
- remove project-specific assumptions;
- review for instruction conflicts;
- test the skill on representative prompts.
