# Process Modeling

1. Scope trigger/outcome.
2. Identify lanes/actors.
3. Identify tasks/events/gateways.
4. Identify supported alternate/exception paths.
5. Update `models/process/`.
6. Validate reachability/termination.
7. Render BPMN/Swimlane views.

Never use the diagram itself as the source of truth.
