# Project Discovery

Read first. Do not modify application source code during discovery.

Output:
- FACTS
- ASSUMPTIONS
- OPEN QUESTIONS
- CURRENT STATE
- SCOPE / NON-GOALS
- ACTORS
- EXTERNAL SYSTEMS
- CONSTRAINTS

Use existing code/config/database/docs as evidence of current behavior.
