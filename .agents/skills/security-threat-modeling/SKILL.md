# Security Threat Modeling

For this middleware inspect Discord input, web UI, API credentials, GitHub access, webhooks, model/provider access, prompt/tool injection, cross-user data isolation, and sensitive logs.

Threats must map to concrete system elements/flows. Controls must map to threats or requirements.
