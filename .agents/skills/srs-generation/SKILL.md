# SRS Generation

Canonical inputs:
`models/requirements/`, use cases, business rules, constraints.

Core sections:
Purpose, Scope, Actors, Overview, FR, NFR, BR, Security Requirements, Constraints, Assumptions, Open Questions, Traceability.

Do not invent requirements to make the document look complete.
