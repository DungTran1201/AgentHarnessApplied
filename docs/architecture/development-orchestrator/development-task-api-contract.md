# Development Task API Contract Specification
## AI-Chan Development Orchestrator

> **Document ID:** API-TSK-01  
> **Version:** 1.0.0  
> **Base Path:** `/api/v1/orchestrator/tasks`  
> **Auth:** Bearer JWT or Session Cookie (`get_current_user`) for User APIs; Bearer Runner Secret Key for Runner Ingestion APIs.  
> **Standard Error Envelope:** `{"detail": {"code": "ERROR_CODE", "message": "Readable explanation", "context": {}}}`

---

## 1. Summary of Endpoints

| Category | Method | Path | Auth Scope | Description |
|---|---|---|---|---|
| **Task Management** | `POST` | `/tasks` | User | Create a new task (supports `Idempotency-Key`) |
| **Task Management** | `GET` | `/tasks` | User | List tasks with filters (workspace, status, runtime) |
| **Task Management** | `GET` | `/tasks/{id}` | User | Get task detail, attempt status, and metrics |
| **Lifecycle Action** | `POST` | `/tasks/{id}/dispatch` | User | Trigger execution dispatch (`DRAFT` -> `QUEUED`) |
| **Lifecycle Action** | `POST` | `/tasks/{id}/approval` | User | Submit plan/tool approval (`APPROVED` / `REJECTED`) |
| **Lifecycle Action** | `POST` | `/tasks/{id}/cancel` | User | Abort running task (`RUNNING` -> `CANCELLING`) |
| **Lifecycle Action** | `POST` | `/tasks/{id}/retry` | User | Create a new attempt for a failed task |
| **Lifecycle Action** | `POST` | `/tasks/{id}/review` | User | Final review decision (`APPROVE`, `REQUEST_CHANGES`, `REJECT`) |
| **Telemetry & Stream**| `GET` | `/tasks/{id}/events` | User | SSE endpoint for live streaming and replaying events |
| **Artifacts & Diff** | `GET` | `/tasks/{id}/diff` | User | Retrieve redacted unified git diff generated by the task |
| **Artifacts & Diff** | `GET` | `/tasks/{id}/artifacts` | User | List artifacts (diffs, test reports, plans) |
| **Verifications** | `GET` | `/tasks/{id}/verifications` | User | List verification steps (lint, typecheck, test, build) |
| **Runner Ingest** | `POST` | `/runners/tasks/verification-reports` | Runner | Runner posts batch of step verification results |
| **Runner Ingest** | `POST` | `/tasks/{id}/events` | Runner | Runner posts batch of normalized events |
| **Runner Ingest** | `POST` | `/tasks/{id}/complete` | Runner | Runner reports terminal completion result |

## 2. User Task Management Endpoints

### 2.1 Create Task
- **Route:** `POST /api/v1/orchestrator/tasks`
- **Headers:** `Idempotency-Key: <client-generated-uuid>` (optional but recommended)
- **Request Body:**
```json
{
  "project_id": "18d5ea64-b99b-4901-ae86-4b70d0bfb35b",
  "workspace_id": "e4b6c31a-5b12-4f88-872e-84b238f83710",
  "title": "Fix token expiration in auth.py",
  "prompt": "Inspect ai-backend/src/core/auth.py and update JWT expiration to 24 hours.",
  "runtime": "antigravity",
  "auto_dispatch": false
}
```
- **Response `201 Created`:**
```json
{
  "id": "tsk_01J9X8A1B2C3D4E5",
  "project_id": "18d5ea64-b99b-4901-ae86-4b70d0bfb35b",
  "workspace_id": "e4b6c31a-5b12-4f88-872e-84b238f83710",
  "title": "Fix token expiration in auth.py",
  "status": "DRAFT",
  "current_attempt": null,
  "created_at": "2026-10-15T10:14:00Z"
}
```

---

### 2.2 Dispatch Task
- **Route:** `POST /api/v1/orchestrator/tasks/{id}/dispatch`
- **Response `200 OK`:**
```json
{
  "task_id": "tsk_01J9X8A1B2C3D4E5",
  "status": "QUEUED",
  "attempt_id": "att_01J9X8A2F3G4H5J6",
  "attempt_number": 1,
  "message": "Task queued for runner dispatch."
}
```
- **Error Responses:**
  - `400 Bad Request`: `WORKSPACE_NOT_READY` — Workspace is `UNAVAILABLE` or `DISABLED`.
  - `409 Conflict`: `WORKSPACE_BUSY` — Workspace currently has another active task modifying files.
  - `409 Conflict`: `TASK_ALREADY_ACTIVE` — An attempt is already running for this task.

---

### 2.3 Submit Approval Decision
- **Route:** `POST /api/v1/orchestrator/tasks/{id}/approval`
- **Request Body:**
```json
{
  "decision": "APPROVED",
  "reason": "Plan looks solid; proceed with file edits."
}
```
- **Response `200 OK`:**
```json
{
  "task_id": "tsk_01J9X8A1B2C3D4E5",
  "status": "RUNNING",
  "message": "Approval transmitted to runner. Execution resuming in accept-edits mode."
}
```

---

### 2.4 Cancel Task
- **Route:** `POST /api/v1/orchestrator/tasks/{id}/cancel`
- **Request Body:**
```json
{
  "reason": "User cancelled after reviewing step 2."
}
```
- **Response `202 Accepted`:**
```json
{
  "task_id": "tsk_01J9X8A1B2C3D4E5",
  "status": "CANCELLING",
  "message": "Termination signal sent to runner. Awaiting process tree cleanup acknowledgment."
}
```

---

### 2.5 Submit Final Review Decision
- **Route:** `POST /api/v1/orchestrator/tasks/{id}/review`
- **Request Body (Accept):**
```json
{
  "decision": "APPROVE",
  "feedback": "LGTM. All verification steps passed."
}
```
- **Request Body (Request Changes):**
```json
{
  "decision": "REQUEST_CHANGES",
  "feedback": "Please add unit tests for missing environment variables."
}
```
- **Request Body (Reject):**
```json
{
  "decision": "REJECT",
  "feedback": "Architecture decision changed; cancelling work item."
}
```
- **Response `200 OK`:**
```json
{
  "task_id": "tsk_01J9X8A1B2C3D4E5",
  "status": "QUEUED",
  "review_status": "CHANGES_REQUESTED",
  "attempt_id": "att_01J9X8B4K2L3M4N5",
  "attempt_number": 2,
  "message": "Changes requested. Follow-up attempt spawned."
}
```

---

### 2.6 Real-Time Event Stream (SSE)
- **Route:** `GET /api/v1/orchestrator/tasks/{id}/events`
- **Headers:** `Last-Event-ID: evt_...` (optional, for replay on reconnect)
- **Response Stream (`text/event-stream`):**
```http
HTTP/1.1 200 OK
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive

id: evt_01J9X8B0
event: TASK_INITIALIZED

id: evt_01J9X8B1
event: TEXT_DELTA
data: {"text_delta": "Analyzing auth.py configuration constants..."}

id: evt_01J9X8B2
event: VERIFICATION_REPORT
data: {"step_name": "test", "status": "PASSED", "duration_seconds": 3.4}
```

```json
  "stat": "ai-backend/src/core/auth.py | 2 +-\n1 file changed, 1 insertion(+), 1 deletion(-)",
  "byte_size": 248
}
```

## 3. Runner Ingestion Endpoints

### 3.1 Post Verification Reports
- **Route:** `POST /api/v1/orchestrator/runners/tasks/verification-reports`
- **Auth:** `Authorization: Bearer <RUNNER_SECRET_KEY>`
- **Request Body:**
```json
{
  "reports": [
    {
      "task_id": "tsk_01J9X8A1B2C3D4E5",
      "attempt_id": "att_01J9X8A2F3G4H5J6",
      "step_name": "test",
      "command": "pytest tests/",
      "status": "PASSED",
      "exit_code": 0,
      "duration_seconds": 4.5,
      "stdout_preview": "18 passed",
      "stderr_preview": ""
    }
  ]
}
```
- **Response `200 OK`:**
```json
{
  "status": "ok",
  "ingested_count": 1
}
```
