# Work Items

A work item represents one user-requested change.

Create:
`work-items/<TYPE-ID>-<short-slug>/`

Suggested lifecycle:
INTAKE -> DISCOVERY -> IMPACT -> DESIGN -> PLAN_REVIEW -> IMPLEMENT -> VERIFY -> SYNC -> RELEASE -> DONE

Do not duplicate final documents inside a work item. Store the change reasoning, impact, selected artifacts, approvals, and verification plan here.
